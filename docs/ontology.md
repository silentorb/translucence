# Translucence ontology

**Translucence** is a collection of **interconnected Bible articles**. The primary units of the corpus are articles; they link to one another so arguments can be composed from reusable pieces rather than written as one-off essays.

A core goal is to present **modular arguments about Biblical truths**: claims, supporting passages, and related articles that can be assembled, reused, and traced.
